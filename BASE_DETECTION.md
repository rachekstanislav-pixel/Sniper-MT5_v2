# BASE-DETECT-2: общий детектор консолидации

## Изменение
Прежний тест `диапазон 8 свечей < 1.5 ATR` находил только узкие сжатия. Он не проверял направленность и перекрытие, поэтому мог пропустить широкий боковик или принять медленный тренд за BASE. В адаптивном режиме обнаружение теперь общее для ATR-входов и Stop-ордеров.

BaseAdaptiveDetection=true (новое значение по умолчанию в исходнике):
- Рассматриваются окна от BaseMinBars=6 до BaseMaxBars=24 закрытых свечей. Выбирается самое длинное подходящее окно.
- Границы — полный максимум High / минимум Low выбранных свечей, включая фитили. Геометрия Фибо, OB, структуры и компрессии не меняется. Цвет и подпись BASE сохранены.
- Полный диапазон / ATR перед началом окна <= BaseMaxRangeATR=4.0. ATR берётся со свечи до самой старой свечи кандидата: спокойные свечи внутри окна и последующий импульс не меняют этот нормализатор.
- Направленная эффективность = abs(последнее закрытие − первое закрытие) / сумма всех abs(изменений закрытий) <= BaseMaxEfficiency=0.35. Значение 1 соответствует однонаправленному ходу, около 0 — возвратному движению.
- Среднее перекрытие соседних свечей >= BaseMinOverlap=0.55. Каждое перекрытие = длина пересечения диапазонов / меньший из двух диапазонов, с ограничением 0..1. Для нулевого диапазона используется проверка попадания в соседний диапазон.
- Невалидные OHLC, неположительный ATR и окна с пропуском торговой свечи не используются. После разрыва торговой сессии модель может найти более короткое непрерывное окно.

Числа 6/24/4.0/0.35/0.55 — начальные параметры модели для сравнения в тестере, а не подобранные по скриншотам значения. Без OHLC-истории выделенные пользователем участки не воспроизведены. По OHLC определяется консолидация; фактическое накопление позиций участниками рынка модель не доказывает.

## Причинность и входы
Stop-режим использует последние закрытые свечи начиная со сдвига 1. Новая база доступна для размещения ордеров до будущего пробоя.
Рыночный ATR-режим использует окно со сдвига 2: только свечи до возможного пробоя свечой 1. При уже активной базе последняя полная допробойная зона обновляет рабочие границы до проверки пробоя. Пробойная свеча не расширяет границы сама для себя. Сохранённая активная база может отработать, даже если новый кандидат не найден.
Уже размещённая пара Stop сохраняет свои уровни до исполнения, истечения срока или отмены; обнаружение новой зоны не двигает существующие ордера. SL/TP, H1/H4-цели, OCO, риск и торговые фильтры не менялись.

## Отрисовка и разрешение торговать
Адаптивная модель обновляется из RefreshMarketContext до проверки торгового состояния. Зона обнаруживается и ставится в очередь отрисовки даже при выключенной автоторговле, стоп-латче или неопределённом исполнении. Сами заявки по-прежнему проходят прежние защиты. Для готового окна обновление выполняется один раз на закрытую свечу; загрузка истории повторяется без потребления этой свечи.

## Диагностика
BaseDetectionDiagnostics=true: строки `SN365 BASE DETECT` с временем, found, bars, rangeATR, efficiency, overlap, low/high.
Причины отказа: RANGE_ATR, DIRECTIONAL_DRIFT, LOW_OVERLAP, SESSION_GAP, INVALID_OHLC. Если все длины отклонены, показаны причина и метрики последнего проверенного (минимального) окна; это не единственная причина всех отклонённых окон. Готовность истории отдельно отмечается HISTORY_NOT_READY/ATR_NOT_READY, не больше одного предупреждения ожидания на свечу. После поступления истории в ту же свечу может появиться итоговая запись.
Отказы торговой части остаются в SN35 SAFETY, размещение — SN365 BASE STOP / SN364 ENTRY. Таким образом можно отдельно проверить обнаружение диапазона и возможность выставить заявку.

## Наборы теста
Перекомпилировать MQ5; стартовая строка содержит BASE-DETECT-2.
1. Sniper_v3_6_5_BASE_ADAPTIVE_ONLY_TEST.set — только BASE Stop, H1/H4 цели, адаптивный детектор, подробная диагностика.
2. Sniper_v3_6_5_BASE_LEGACY_ONLY_TEST.set — те же исходные торговые параметры Stop, но прежний детектор 8 / 1.5 ATR. Для A/B использовать одинаковые даты GOLD/M5, реальные тики, депозит и плечо.
3. Sniper_v3_6_5_BASE_ADAPTIVE_NO_EMA.set — общий набор с новым детектором, Stop-режимом и ранее реализованным OTE, без EMA.

В старых SET отсутствует BaseAdaptiveDetection, поэтому новый исходник использует своё true. Для точного воспроизведения прежнего детектора явно указать false. При false сохранены прежние отдельные расчёты и отрисовка; независимая адаптивная модель выключена.

## Проверки и пределы
check_base_detection.py исполняет реальные функции Evaluate/Select/Read/Update как C++ с имитацией API MT5: широкий боковик, медленный тренд, неперекрывающиеся свечи, фитиль, разрыв сессии, короткое окно, прежний ATR, отсутствие текущей/будущей свечи, загрузка данных и отрисовка при торговых блокировках.
Существующие проверки двух режимов BASE дополнены выбором адаптивных границ и допробойного сдвига; прежний режим также проверяется. Сохранены OTE, OCO, динамический риск и управление ATR-позициями.
Компиляция в MetaEditor и исторический тест MT5 здесь не выполнены. Новый V-разворот в эту правку не входит.
