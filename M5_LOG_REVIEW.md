## Что сделано в новом MQ5
Файл Sniper_Manager_v3_6_5_M5_ALL_MODULES_V3.mq5 создан отдельно, прежние исходники сохранены.
- Все входные модули включены: EMA, Comp, OTE, Sweep, Base, AI. По просьбе пользователя ни один из них не отключён для обхода конкуренции.
- BASE Stop, обе стороны, адаптивная детекция, новый D1 .790/M15 OTE и половинный контртрендовый риск включены значениями исходника. Диагностика BASE также true; SET не нужен.
- Только рабочий график/тест M5; ошибочный таймфрейм явно отклоняется при инициализации. Подтверждение OTE по-прежнему на M15.
- Строка BUILD содержит уникальный id, имя фактически скомпилированного файла и дату компиляции; BASE CONFIG / MODULE CONFIG показывают фактически применённые параметры. SYMBOL показывает минимум/шаг лота, контракт, stops level, баланс/плечо без учётных данных.
- Каждая BASE-кандидатура имеет сторону, границу, SL и TP. SIZE BLOCK показывает модуль, вход, SL, minLotLoss и allowedCash. PORTFOLIO BLOCK показывает уже занятый BUY/SELL объём, лимит объёма, денежный риск и маржу.
- PENDING LIVE выводится только после подтверждённого результата и видимой собственной заявки; BASE FILLED отличает реальное исполнение от кандидата. PENDING CANCEL объясняет OCO/истечение срока/историю/политику/достигнутую цель.
- На графике видны уникальное имя сборки и отдельные последние состояния BASE/OTE. Новые диагностические строки не открывают заявки и не изменяют торговое состояние.
- Учёт экспозиции общий для всех модулей; отмена OCO ограничена собственными BASE Stop на Symbol/Magic. Старые алгоритмы/разметка сохранены. Не добавлено исключений, которые позволяли бы одному модулю превышать общий риск/маржу из-за другого.

## Что намеренно не обходится
Минимальный лот выше бюджета по-прежнему запрещён. Ни дробный виртуальный лот, ни повышение риска, ни произвольное приближение стопа ради входа не применялись. Стоп/выход OTE остался прежним: за дальней границей D1 с InvalidationPoints; BASE имеет согласованный локальный стоп и H1/H4 цель. Перенос стопов/выходов OTE требует отдельного решения.
Депозит 500 USD не гарантирует пригодность всех стопов: при текущей кривой обычный бюджет около 16.10 USD, контртрендовый — 8.05 USD. На нём часть BASE/OTE может проходить, часть — нет. Тест check_reported_cash_risk.py демонстрирует оба исхода и не подменяет исторический прогон.
Депозит, торговый контракт и минимум лота задаёт тестер/брокер. Советник не меняет виртуальный баланс и не рисует несуществующие исполнения, чтобы скрыть ограничения.
