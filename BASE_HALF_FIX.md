# BASE HALF FIX — единое сопровождение остатка

Актуальный файл: `Sniper_Manager_v3_6_5_BASE_HALF_1000_TP_2000_FIX.mq5`.

Исправляет подтверждённый журналом конфликт после частичного закрытия: старый корзинный менеджер переносил SL в BE и закрывал остаток в ту же секунду. В новой BASE-only сборке действует один менеджер всех собственных позиций Symbol/Magic; комментарий позиции не влияет на её сопровождение после partial. Старое корзинное сопровождение удалено, остаток блокирует повторный набор ордеров.

Торговые условия сохранены:

- Buy Stop на High, Sell Stop на Low последних восьми закрытых свечей; SL за противоположной границей на 0.50.
- Контртрендовые входы BASE разрешены; данные и риск проверяются. Остальные модули выключены.
- Заявляемый вход от 0.02, округление объёма вниз для точного деления; если риск не позволяет — отказ.
- Половина после +1000 пипс (=10.00 цены), остаток по фиксированному TP +2000 (=20.00) от фактического исполнения.
- Без BE и трала. SL не перемещается; общая защита риска сохраняется.

Ограничения частичного исполнения, маркера при неопределённом результате и работы советника/терминала описаны в [правилах половинного выхода](BASE_HALF_1000_TP_2000.md). Новый FIX сохраняет эти ограничения. После partial комментарий больше не требуется ни для управления остатком, ни для запрета нового набора.

[Подробный разбор журнала и воспроизведение ошибки](reports/20261101_half_execution_review.md).

```sh
python3 tests/check_boundary_dispatch_fix.py
python3 tests/check_boundary_partial_fix.py
```

Настройки встроены; выбрать новое имя `BASE_HALF_1000_TP_2000_FIX`, GOLD/M5, без старого SET. Строка старта `SN365 BASE HALF FIX CONFIG`. Устаревшие входные параметры корзинного TP/BE удалены.

MetaEditor и MT5 здесь отсутствуют: EX5 и исторический прогон новой сборки не выполнены. Проверки исполнения используют C++ и имитацию MT5 API. Положительный результат стратегии не гарантируется.
