# Контрольная сборка только с BASE

Файл: `Sniper_Manager_v3_6_5_BASE_ONLY_CONTROL.mq5`.

Основа — `BASE_ATR_RESTORED_VISUAL`. Изменены только пять значений по умолчанию: EMA, Compression (включая парный лимит), OTE, отдельный Sweep и AI выключены. BASE включён, `BaseUseStopOrders=false`. Все функции, остальные параметры и визуализация совпадают с восстановленной версией буквально; изменено также описание сборки.

Это контроль исходного BASE: вход по закрытию свечи за границей восьмисвечной зоны, прежние H4/D1-фильтры, прежний локальный SL, ATR-тейк, безубыток и общая защита риска. Правила 65/35, трал и частичный выход из FIX2/FIX3 не включены.

Цель — проверить BASE без конкуренции других модулей за объём и риск. Отказы по H4/D1, минимальному лоту и собственному лимиту объёма по-прежнему возможны; отключение конкурирующих модулей не гарантирует прохождение этих проверок. Анализировать нужно число `SN365 BASE` и следующие за ними причины отказов/подтверждения `SMC_Base_ATR`, а не только количество прямоугольников.

Настройки встроены в MQ5, SET не нужен. Для сравнения: GOLD/M5, тот же период 1–15 октября 2026 и тот же депозит; новое имя советника, без загрузки старого SET. Для денежной оценки выключить режим тестера «Расчёт прибыли в пунктах»: он является настройкой самого тестера и не задаётся исходником советника.

Проверка нормализацией исходника подтвердила, что кроме пяти переключателей и описания отличий от BASE_ATR_RESTORED_VISUAL нет. MetaEditor и MT5 здесь недоступны: EX5 и исторический прогон этой сборки не выполнены.
