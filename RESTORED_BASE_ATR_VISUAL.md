# Откат к BASE_ATR с последней визуализацией

Рекомендуемый файл: `Sniper_Manager_v3_6_5_BASE_ATR_RESTORED_VISUAL.mq5`.

База — именно `Sniper_Manager_v3_6_5_BASE_ATR.mq5`, указанный пользователем, а не BASE_ATR_v2, FIX2 или FIX3. Исходный файл сохранён без изменений.

Все торговые функции, настройки, фильтры, модули, расчёт лота, H4-реконструкция и управление позициями возвращены буквально из BASE_ATR. В частности, Compression и отдельный Sweep включены как в оригинале, `BaseUseStopOrders=false`; первоначальные BE/TP и ATR-правила снова действуют. Нет переноса 65/35, общего трала, частичного закрытия и новых состояний BASE из FIX2/FIX3.

Оставлены только визуальные изменения: общий информационный блок справа, плотный шаг таймфреймов, одна строка сводных показателей. Панель, фон, дополнительные диагностические подписи и маска перекрытия используют согласованные правые координаты. Фиктивной надписи о новом трале/частичном закрытии нет. Геометрия зон и линии управления восстановлены как в BASE_ATR; уровни 35/50/65 из FIX3 не рисуются.

Добавлены только визуальная настройка `HudWidthPercent=72` и координата `G_HudLeft`. На узком графике длинный текст сокращается; полная строка остаётся в tooltip. Отдельный SET не требуется; используйте новое имя файла, чтобы тестер не наследовал настройки FIX2/FIX3.

Проверка:

```sh
python3 tests/check_restored_visual.py
```

Проверяется точное совпадение всех 146 невизуальных функций с BASE_ATR. Затем весь оставшийся исходник также сравнивается, с разрешением только списка из 10 функций отрисовки, новой визуальной настройки/координаты и описания сборки. Тест выполняет реальные функции координат/сводки через C++-имитацию MT5 на ширинах 800–2560 px.

MetaEditor и MT5 здесь отсутствуют: EX5 не собран, фактическая отрисовка и исторический тест восстановленного файла не выполнены.
