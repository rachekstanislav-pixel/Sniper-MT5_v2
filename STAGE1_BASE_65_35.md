# FIX2: BASE 8 / 65–35 и общий выход по теням

Рекомендуемый файл: **`Sniper_Manager_v3_6_5_BASE_FIX2.mq5`**. Текущий `Sniper_Manager_v3_6_5_STAGE1_BASE_65_35.mq5` обновлён тем же исходником. Основа FIX2 — добавленный пользователем `Sniper_Manager_v3_6_5_BASE_ATR_v2.mq5`; исходный загруженный файл сохранён. Оставлено ограниченное исправление H4-реконструкции, чтобы старый H4-event не блокировал входы.

Compression (рынок и парный лимит) и отдельный Sweep по указанию пользователя выключены. EMA, OTE, BASE, AI остаются включены. Подтверждение sweep внутри OTE не отключается. При переносе на работающий счёт собственные отложенные ордера выключенных модулей удаляются; открытые собственные позиции продолжают сопровождаться общим менеджером. Чужой Magic и ручные позиции не изменяются.

## BASE

Стабильный детектор: High/Low по восьми закрытым свечам с индексами 2..9; свеча 1 подтверждает нахождение закрытия внутри. Сохранено прежнее ограничение ширины `< 1.5 ATR`. Никакого адаптивного окна 6–24 в FIX2 нет.

- Buy Stop = `Low + 0.65 × (High−Low)`; SL = `Low − 50 × 0.01`.
- Sell Stop = `Low + 0.35 × (High−Low)`; SL = `High + 50 × 0.01`.
- Зона разделена линией 50%; дополнительно показаны уровни 35%/65%.
- TP = 0. H1/H4-экстремум для тейка не нужен.

Границы активного ордерного набора не двигаются. Если одна сторона временно недопустима по котировке или риску, повторяется только она, с интервалом 5 секунд. Stop позади рынка не размещается. После первого исполнения встречный собственный BASE-pending отменяется; OCO восстанавливается по истории. Клиентское OCO не исключает полностью исполнение обеих сторон при резком движении.

Использованная зона блокирует только повтор того же времени начала, а не любые будущие зоны. Срок — 10 M5-баров; по истечении остаток ордеров отменяется. История исполнения должна быть доступна, общие лимиты риска/объёма/маржи не обходятся.

## Общий выход для всех собственных модулей

По уточнению пользователя применяется ко всем собственным позициям на символе с Magic советника, включая оставшиеся позиции отключённых модулей.

BUY подтягивает SL за минимальной Low, SELL за максимальной High последних 3–5 закрытых свечей M5; по умолчанию 5. Формирующаяся свеча исключена. Начальный SL не расширяется, stops/freeze брокера соблюдаются. Правила безубытка нет. Трал может естественно пройти цену входа.

Нативный TP новых входов равен 0; TP существующей собственной позиции снимается с сохранением SL. Старый виртуальный корзинный TP и BE больше не вызываются. При +1000 пипс (10.00 цены: BUY по Bid, SELL по Ask) закрывается половина исходного объёма, округлённая вниз к шагу лота. Остаток идёт по тралу. Общая защита по риску продолжает действовать.

История учитывает уже закрытый объём, включая ручные частичные закрытия. Маркер по POSITION_IDENTIFIER сохраняется до запроса, чтобы повторный тик или перезапуск не делил позицию ещё раз. При однозначном отказе повтор возможен через 60 секунд; при неопределённом результате нужен контроль истории, автоматического повторного закрытия нет. При частичном исполнении IOC закрытый объём может быть меньше запрошенного.

Минимальный лот 0.01 при шаге 0.01 остаётся целиком под тралом. Для 0.03 закрывается 0.01, остаётся 0.02. Лот не увеличивается ради частичной фиксации.

## Значения в MQ5

| Параметр | По умолчанию |
|---|---:|
| `BasePipSize` | 0.01 цены |
| `BaseInitialSLPips` | 50 (отступ 0.50) |
| `BaseTrailBars` | 5 (допустимо 3–5) |
| `BaseTrailBufferPips` | 0 |
| `BaseHalfExitPips` | 1000 (движение 10.00) |
| `BaseEntryRetrySeconds` | 5 |
| `BaseMaxWaitBars` | 10 |
| `EnableSMC_Comp` | false |
| `EnableSMC_Sweep` | false |
| `HudWidthPercent` | 72, блок справа |

`Fixed_TakeProfit`, `Physical_BE_Trigger`, `Physical_BE_Level` сохранены как параметры совместимости; в FIX2 они не управляют выходом. Отдельный SET не нужен. Новое имя BASE_FIX2 предотвращает применение параметров, сохранённых тестером для предыдущего имени советника. Загружать старый SET в FIX2 не следует: он может включить отключённые модули.

Проверяются фактические извлечённые функции: ордера без TP, OCO, выключенные модули и удаление их pending; воспроизведение старого блокирования новой зоны и повтор недостающей стороны; общий менеджер на EMA/Comp/OTE/Sweep/AI, частичное закрытие один раз и перезапуск; координаты панели и уровни зон; OTE, объём/риск, экспозиция, H4. 12 исходных функций защиты/геометрии сохранены буквально; изменённые функции панели проверяются отдельно.

Это C++-проверки логики с имитацией MT5 API. MetaEditor/MT5 здесь отсутствуют: EX5 не собирался, исторический тест новой сборки и фактическая отрисовка не выполнялись. [Разбор реального предоставленного журнала](reports/20261101_review.md) относится к прежним сборкам, а не к доходности FIX2.
